# 🌟 간판지원단 - 경기도 소상공인 경영환경개선사업 포털 & 모바일 PWA

> **경기도 소상공인의 성공적인 점포 운영과 노후 간판 정비를 지원하기 위한 스마트 웹 서비스입니다.**  
> 실시간 간판 시뮬레이터를 통해 간판 디자인을 가상 배치해 보고, 경기도 지원사업의 자격 검토부터 AI 비서의 실시간 맞춤 상담까지 한곳에서 원활하게 제공합니다.

---

## 📱 서비스 개요

본 서비스는 PC 웹 포털 및 스마트폰 브라우저에 최적화된 **Progressive Web App (PWA)** 규격의 모바일 애플리케이션으로 설계되었습니다. 노후화된 점포 간판을 교체하고자 하는 경기도 내 소상공인들이 사업 공고 정보를 직관적으로 습득하고, 간판을 가상 디자인하여 간편하게 교체를 신청하도록 돕습니다.

* **PC 웹 서비스**: `index.html` (메인 웹 포털), `dashboard.html` (소상공인/관리자용 관리 대시보드)
* **모바일 웹앱 서비스 (PWA)**: `app.html` (모바일 홈 피드 및 모달 팝업 최적화 뷰)

---

## ✨ 핵심 기능 (Key Features)

### 1. 🎨 실시간 간판 시뮬레이터
* 제공되는 가상 건물 파사드(Facade) 또는 사용자가 직접 촬영한 점포 사진 위에 다양한 간판 및 썬팅 디자인을 얹어서 미리 확인해볼 수 있는 실시간 2D/3D 연출 툴입니다.
* 글꼴 변경, 색상 조정, 조명 투광기 효과 등을 즉각적으로 제어할 수 있습니다.

### 2. 🤖 경기도 지원사업 특화 "AI 비서"
* 경기도 소상공인 경영환경개선사업 공고(PDF)의 정밀 데이터가 내장된 맞춤형 지식 비서 챗봇입니다.
* **지원 자격 및 대상** (창업 3년 이상 소상공인 요건, 배제 업종 등)
* **지원 금액 및 한도** (업체당 최대 200만원 한도 및 공급가 100% 지원 상세 규정)
* **제출 서류 간소화** (경기바로 공공마이데이터 간편 신청 동의 연동 서류)
* **신청 일정 및 방법** (3월 31일 ~ 4월 13일 접수 기간 및 경상원 6대 지역센터 전화망/주소)

### 3. ✍️ 교체 후기 관리 & 실시간 입력 검증
* 소상공인들이 직접 작성하는 솔직한 간판 교체 후기 시스템이 탑재되어 있습니다.
* 지역 및 상호명(최대 25자), 상세경험담(최대 150자)에 대한 **실시간 글자수 계산기 및 강력 타이핑 한도 제한(`maxlength`)** 검증이 적용되어 무분별한 데이터 입력을 방지합니다.

### 4. 📲 모바일 반응형 UX/UI 및 가상 키보드 가림 완벽 극복
* 모바일 기기 접속 시 뜨는 **공지사항 팝업창**이 화면 밖으로 이탈하지 않도록 미디어 쿼리를 사용해 화면 정중앙에 완벽하게 고정했습니다.
* 스마트폰에서 글을 작성할 때 **가상 키보드가 솟구쳐도 후기 작성란이 가려지지 않고**, 세로 스크롤을 이용해 작성 중인 내용을 실시간 확인하며 터치 스크롤 할 수 있는 모바일 최적화 스펙이 완비되어 있습니다.
* 구글 ID 로그인 및 카카오톡 간편 로그인 단추가 찌그러지지 않고 모바일에 적합한 시원한 가로형 바 버튼 형태로 정렬(세로 2줄 나열)됩니다.

## 🛠️ 기술 스택 (Tech Stack)

* **Frontend**: HTML5, Vanilla CSS3 (Custom Responsive Layouts), JavaScript (ES6+), FontAwesome Icons, Noto Sans KR / Outfit Web Fonts
* **Web App (PWA)**: `manifest.json` (웹앱 선언부), `sw.js` (서비스워커를 통한 자산 오프라인 캐싱 및 구동 최적화)
* **Packaging**: PowerShell 기반 패키징 스크립트 (`간판지원단_모바일앱.zip` 생성)

## 🚀 로컬 실행 방법 (How to Run)

본 프로젝트는 Node.js 환경에서 간편한 로컬 서버 구동을 지원합니다.

### 1. 의존성 패키지 설치
프로젝트 루트 경로에서 로컬 웹 서버 실행 환경을 구축합니다.
```bash
npm install
```

### 2. 로컬 웹 서버 실행
포트 `8080`번으로 웹 서버를 기동하여 모바일 및 PC 뷰를 확인합니다.
```bash
# 로컬 개발 서버 실행
npm run dev
```

### 3. 모바일 실물 기기 테스트 (로컬 터널링)
가정이나 사무실 내의 Wi-Fi를 이용하여 실제 안드로이드/아이폰 스마트폰 브라우저에서 직접 테스트할 수 있도록 터널링 환경을 엽니다.
```bash
# 로컬 서버와 터널 동시 가동
npm run start
```
* **PC 메인 포털 접속**: `http://localhost:8080/index.html`
* **모바일 PWA 앱 접속**: `http://localhost:8080/app.html` 또는 터널 주소로 접속

## 📦 모바일 패키징 및 배포

PWA 모바일 앱의 릴리즈 배포 파일을 제작하기 위해 아래 명령어를 사용해 패키지 압축본을 생성합니다.
```bash
npm run package
```
* 빌드가 완료되면 루트 경로에 `간판지원단_모바일앱.zip` 파일이 갱신되어 생성됩니다.
