# 점포 환경개선 추진계획서 AI 자동작성기 절대 행동 헌법 (Plan Generator Discipline)

> **적용 대상**: `GP Implementation Plan/` 내 모든 파일 (`plan-generator.html`, `GP_SYSTEM_BLUEPRINT.md`, `PLAN_RULES.md`, `verify-plan.js`)  
> **상호 격리 헌법**: 간판지원단 본체 서비스(`index.html`, `app.js`, `SYSTEM_BLUEPRINT.md`)와 100% 영구 분리  
> **전용 검문소**: `GP Implementation Plan/verify-plan.js` (`npm run verify:plan`)

---

## 🏛️ 에이전트 절대 준수 6대 행동 강령 (The 6 Commandments)

### 1. 파트당 2문장, 총 8문장 규격 절대 사수 (Zero 1-Sentence Truncation)
- AI 모델의 단문 요약(1개 문장 축약) 습성을 100% 엄격 금지한다.
- `part1`부터 `part4`까지 모든 파트는 반드시 사연과 계획이 담긴 **"정확히 2개의 긴 완성형 문장(총 8문장 체계)"**으로 작성해야 한다.
- 어떠한 경우에도 400자 미만 단문이 화면에 노출되는 것을 영구 금지하며, 목표 분량인 **445자 이상 485자 이하**를 철저히 지킨다.

### 2. 구걸/과장 표현 4대 금지어 100% 영구 배제 (Dignified Professional Tone)
- 심사위원에게 동정을 구걸하거나 비굴한 톤의 표현을 일체 쓰지 않는다.
- **[4대 절대 영구 금지어]**:
  1. ❌ **'마중물'** ➔ 절대 사용 금지! (`도약의 발판`, `새로운 전환점` 사용)
  2. ❌ **'영업 마비'** ➔ 절대 사용 금지! (`신규 고객 유입 정체`, `점포 가시성 저하` 사용)
  3. ❌ **'절박한 처지', '처지'** ➔ 절대 사용 금지! (`경영 여건`, `영세 사업장 환경` 사용)
  4. ❌ **'절실합니다', '절실'** ➔ 절대 사용 금지! (`경영 정상화에 큰 힘이 됩니다`, `반드시 필요합니다` 사용)
- 성실하게 일터를 지켜온 소상공인의 당당한 긍지와 객관적인 시설 노후화 사실만을 품격 있는 공공행정 용어로 서술한다.

### 3. 4. 기대효과 내 "매출 상승 효과" 명시적 100% 필수 포함 (Revenue Growth Law)
- 4. 기대효과 항목에는 지원 사업의 실질적 경제성과를 입증하기 위해 **반드시 "가시적인 매출 상승 효과를 거두고" (또는 "매출 상승 효과") 표현을 100% 명시적으로 포함**해야 한다.
- 누락 시 자동 정제 필터(`sanitizePlanText`)가 문맥에 맞추어 강제 결합한다.

### 4. 3단계 방어벽 아키텍처 절대 수호 (3-Tier Defense Architecture)
- **1차**: 프롬프트 헌법 (8문장 체계, 금지어 4대 배제, 매출 상승 효과)
- **2차**: 400자 미달 감지 시 백그라운드 2차 자동 확장 엔진 (`expansionPrompt`)
- **3차**: 자바스크립트 결정론적 강제 보강 (`enforceMin400Chars`) & 실시간 자동 정제 필터 (`sanitizePlanText`)
- 3단계 방어벽을 우회하거나 약화시키는 코드 변경을 100% 영구 금지한다.

### 5. 500자 전산 한도 사수 및 4번 항목 종결 마침표 보존 (Part 4 Protection)
- 공단 전산 등록 한도인 최대 500자를 엄수하되, 500자 클리핑 시 **4번 기대효과 항목 전체가 잘려나가는 사고를 원천 방지**한다.
- 반드시 4번 항목의 종결 마침표(.)에서 안전하게 마감되어야 한다.

### 6. 본체와의 상호 완전 분리 헌법 준수 (Strict Module Isolation)
- `plan-generator.html` 내에 간판지원단 본체의 라이브러리(`supabase-config.js`, `data-store.js`, `app.js` 등)를 절대 포함하지 않는다.
- 본체의 소스 코드에 추진계획서 로직을 혼입하지 않는다.
- 수정 작업 후 반드시 `npm run verify:plan` 전용 검문소와 `npm run verify` 본체 검문소를 모두 100% 통과시킨 후 배포한다.

### 7. 8년 이상 장기 운영 점포 운영 기간({N}년간) part1 문두 필수 명시 (Long-Term Operation Duration SSOT)
- 8년 이상 운영된 모든 점포는 part1(사업체 소개) 첫 번째 문장에 반드시 **"지난 {N}년간 한자리에서..."** 또는 **"{N}년간..."**과 같이 구체적 기간을 문두에 직접 명시하여 오랜 세월 점포를 운영해 온 신뢰와 역사를 강력하게 각인시킨다.
- AI 누락 시 `enforceMin400Chars` 결정론적 보강 엔진이 브라우저 화면 출력 직전에 개입하여 기간 표현을 100% 강제 주입·보정한다.
